# CEM Multi-Tool

A lightweight Python command-line utility featuring around 20 useful functions for networking, cryptography/hashing, system diagnostics, and various utilities.

## Features

### Networking
- Target pinging
- Public and local IP retrieval
- DNS lookup
- Port scanner (ports 21, 22, 80, 443, 3306, 8080)
- HTTP header inspection

### Security & Cryptography
- Base64 encoder / decoder
- SHA-256 hashing
- Hexadecimal key generator
- Password strength checker
- Password generator

### System & Utilities
- System information
- Byte unit converter (KB/MB/GB)
- UUID generator
- Text <-> Binary converter
- Countdown timer
- Current date and time

### Miscellaneous
- Weather info (via wttr.in)
- Temperature converter
- Palindrome checker
- Dice roller
- Text mirror / reverser
